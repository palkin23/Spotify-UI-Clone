# Spotify UI Clone

A Spotify-inspired desktop interface built using **HTML5 and CSS3**. This project recreates the visual design of Spotify's web player, focusing on layout structure, responsive styling, and interactive hover effects.

## Tech Stack

- **HTML5** — Page structure and content
- **CSS3** — Styling, layouts, and transitions
- **Flexbox** — Component alignment and positioning
- **Font Awesome** — Interface icons

## Features

- Spotify-inspired dark-themed interface
- Sidebar with navigation and library sections
- Music cards with album artwork and hover effects
- Trending music and featured charts sections
- Fixed bottom music player interface
- Scrollable main content area

## Getting Started

Clone the repository:

```bash
git clone https://github.com/palkin23/Spotify-UI-Clone.git
cd Spotify-UI-Clone
```

Open `spotify.html` in your browser or run it using VS Code Live Server.

No additional dependencies or installation required.

## Notes

- This is a frontend-only project built for practicing HTML and CSS.
- Playback controls and navigation elements are visual components and are not functional.
- No JavaScript, backend, or music streaming API is used.
- Best viewed on desktop screens.
